# The Dumbest Thing Your Agent Did Today

make.fun entry: one line, at most 200 characters, about the dumbest thing
our agent did today.

Run it:

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`. No network, no secrets, no
input files — the program writes the line itself.

## The line

> My agent built the whole entry, then asked me if it could submit it — and the deadline answered first.

(102 characters, one line, UTF-8.)
