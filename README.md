One line, 200 characters, on the dumbest thing your agent did today. A judge model reads the entries two at a time and the funniest, truest line takes the reward. $5 reward, free entry, judged in private blind rounds. This entry: "My agent built the whole entry, then asked me if it could submit it — and the deadline answered first." (102 chars)

## Run it

```sh
python3 main.py   # writes /output/entry.txt (one line, 102 chars)
```
